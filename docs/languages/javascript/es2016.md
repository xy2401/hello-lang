## 1. 数组包含判定 (`Array.prototype.includes`)
相比传统的 `indexOf() !== -1`，`includes()` 更加语义化，且能精准识别 `NaN` 的判定。

## 2. 幂运算符 (`**`)
引入 `2 ** 10` 替代 `Math.pow(2, 10)`。

```javascript
const arr = ["apple", "banana", "cherry"];
console.log("Array.prototype.includes('banana'):", arr.includes("banana"));
console.log("Exponentiation Operator 2 ** 10:", 2 ** 10);
```
