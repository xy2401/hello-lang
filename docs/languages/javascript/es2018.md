## 1. 对象解构与展开 (`Rest / Spread`)
将解构赋值与展开运算符拓展至 Object 领域。

```javascript
const obj = { a: 1, b: 2, c: 3 };
const { a, ...rest } = obj;
console.log("Rest properties:", rest);
console.log("Spread properties:", { ...rest, d: 4 });
```
