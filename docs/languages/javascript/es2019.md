## 2. 键值对逆向组装 (`Object.fromEntries`)
将二元数组转换为 Object 对象。

```javascript
const nested = [1, [2, [3]]];
console.log("Array.prototype.flat(2):", nested.flat(2));
const entries = [["name", "Alice"], ["role", "Admin"]];
console.log("Object.fromEntries:", Object.fromEntries(entries));
```
