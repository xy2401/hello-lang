## 1. 纯函数不可变数组方法 (`toSorted`, `toReversed`, `toSpliced`, `with`)
修改数组时返回新的拷贝，不改变原始原数组。

```javascript
const nums = [3, 1, 4, 1, 5, 9];
console.log("Array.prototype.toSorted():", nums.toSorted());
console.log("Original Array Unmutated:", nums);
console.log("Array.prototype.with(2, 99):", nums.with(2, 99));
```
