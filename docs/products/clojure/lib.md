# Clojure 常用外部依赖库（Clojars/Maven）

## 📦 Web 框架
- **Ring** - HTTP 抽象层（基础）
- **Compojure** - HTTP 路由库
- **Pedestal** - 全功能 Web 栈
- **Re-frame** - 前端 + 后端全栈框架

## 🗄️ 数据库与持久化
- **Datomic** - 不可变数据库（原子）
- **HikariCP** - JDBC 连接池
- **Java-JDBC** - Java 生态兼容

## 🧪 测试工具
- **clojure.test** - 标准测试库
- **Midje** - BDD 风格测试
- **Speccy** - 数据规格验证

## 🔧 实用工具库
- **Cheshire** - JSON 处理
- **Core.async** - 异步编程通道
- **Spec.alpha** - 数据规范验证
- **Enlive** - HTML 模板
- **Hiccup** - HTML 构建器

## ⚠️ 已废弃/不推荐
- **Incani** 🔴 - 旧 HTTP 客户端，建议使用 Ring/HTTPer
- **Carmen** 🔴 - CSS 生成器，较少维护
