# C++ 常用外部依赖库（第三方）

## 📦 功能扩展库
- **Boost** - C++ 功能扩展大全（必备知识）
- **fmt** - 类型安全的格式化库（现代 printf 替代）
- **ABI 兼容性工具** - abseil（Google 开源库）

## 🎨 GUI 与图形
- **Qt** - 跨平台 GUI 框架（最成熟）
- **SDL2** - 简单游戏和多媒体开发
- **Dear ImGui** - Immediate Mode GUI
- **imgui** - 即时模式 UI 库

## 🔬 专业领域库
- **OpenCV** - 计算机视觉（最流行）
- **Eigen** - 线性代数运算
- **Bullet Physics** - 物理引擎
- **Assimp** - 3D 模型导入导出

## 🌐 网络与序列化
- **Boost.Asio** - 异步网络编程
- **gRPC-Cpp** - Google RPC 框架
- **Protocol Buffers** - Google 序列化协议
- **CURL** - HTTP/FTP客户端库

## 🧪 测试工具
- **Catch2** - 现代 C++ 测试框架
- **GoogleTest** - Google 单元测试框架
- **Benchmark** - Google 性能基准测试

## 🏗️ 构建工具
- **CMake** - 跨平台构建系统（标准）
- **vcpkg** - 包管理器（Microsoft）
- **Conan** - C/C++包管理工具

## ⚠️ 已废弃/不推荐
- **Tr1** 🔴 - C++03 TR1，已被 C++11 原生支持替代
- **Xtreme** 🔴 - 非标准扩展库
