# C# 总览


C# 是 .NET 生态的静态类型语言，适合应用、服务与工具开发。本卷已有 C# 12 / .NET 8 LTS 等版本专题。

- [C# 12 / .NET 8 LTS](./version/dotnet-8.md)

## 适用边界

适合 .NET 应用与强类型开发；语言版本、目标框架和 SDK 版本是不同层次。当前 C# 容器工作台标记暂不可用，优先按安装页在本机实践。

## 版本阅读范围

[完整版本目录](./version/)收录本仓库已有专题（如 csharp-10、csharp-13、csharp-14-dotnet-10）。这些是教学与兼容性对照入口；运行环境的具体版本以安装页、工作台或采集证据为准。

## 推荐学习路线

[安装与环境](./install) → [基础语法](./basic) → [数据结构](./data-structures) → [算法](./algorithms) → [完整版本目录](./version/)。先完成最小示例，再阅读版本差异。
