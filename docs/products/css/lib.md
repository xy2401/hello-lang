# CSS 常用类库索引

CSS 用于样式设计和响应式布局，拥有丰富的工具和框架。

## 📦 CSS 核心特性

### 现代特性
- **Flexbox** - 一维弹性盒子布局
- **Grid** - 二维网格布局系统
- **CSS Variables** - 自定义属性
- **Animation** - transition、@keyframes
- **Shadow DOM** - 组件封装

### 响应式设计
- **媒体查询** - @media, min-width, max-width
- **视口单位** - vw, vh, vmin, vmax
- **移动优先** - Mobile-first design
- **容器查询** - @container（新特性）

### CSS 预处理器
- **Sass/SCSS** - 最流行的预处理器
- **Less** - 跨平台预处理器
- **Stylus** - 灵活的语法风格

### CSS 框架
- **Bootstrap** - 完整的 UI 组件库
- **Tailwind CSS** - Utility-first 设计
- **Bulma** - Flexbox 基础框架
- **Materialize** - Material Design 实现
- **Foundation** - 响应式网格系统

### CSS-in-JS
- **Styled-components** - React + CSS
- **Emotion** - React/Vue 样式方案
- **Linaria** - Zero-runtime 方案

### 工具链
- **PostCSS** - CSS 预处理插件
- **Autoprefixer** - 前缀自动添加
- **PurgeCSS** - 移除未使用样式

---

*注：Tailwind CSS 是现代项目的主流选择*
