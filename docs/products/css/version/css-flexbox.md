> **参考官方文档**：[CSS 官方发布说明](https://www.w3.org/Style/CSS/current-work)

## 版本定位

- **发布时间：** 2015 年 6 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** CSS

## 核心变化

**主要功能与架构演进：**

- 一维弹性盒子排版（`display: flex`）
- 彻底消除了传统 `float` 浮动与 `inline-block` 垂直居中对齐的痛点

**工程影响与选型建议：**

> 全网 Web 布局的事实标准基石。
