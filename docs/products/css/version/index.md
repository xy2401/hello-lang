# CSS 版本演进

CSS 采用模块化独立标准化推进。近年 CSS 迎来了自诞生以来最密集的现代化核心语法突破。

## 版本索引

### [现代 CSS (2023–2024)](./modern-css)

- **发布时间：** 2023 年–2024 年
- **版本重点：** 原生 CSS 嵌套（CSS Nesting &）：原生支持选择器嵌套，告别对 Sass/Less 预编译器的绝对依赖。

### [CSS Grid 布局](./css-grid)

- **发布时间：** 2017 年 3 月
- **版本重点：** 二维网格布局系统（display: grid）全量普及于各大现代浏览器。

### [CSS Flexbox 布局](./css-flexbox)

- **发布时间：** 2015 年 6 月
- **版本重点：** 一维弹性盒子排版（display: flex）。

### [CSS3 模块化](./css3)

- **发布时间：** 2011 年起
- **版本重点：** 媒体查询（Media Queries @media）开启移动优先响应式设计（RWD）时代。

## 浏览器兼容建议
- 现代特性（如 `:has()` 与 原生 Nesting）在 2023+ 主流浏览器均已全量支持（Baseline 普及），无需配置额外 Polyfill。
