# CSS 版本演进

CSS 采用模块化独立标准化推进。近年 CSS 迎来了自诞生以来最密集的现代化核心语法突破。

## 核心版本演进与关键里程碑

### 现代 CSS (2023–2024)（2023 年–2024 年）

**主要功能与架构演进：**

- **原生 CSS 嵌套（CSS Nesting `&`）**：原生支持选择器嵌套，告别对 Sass/Less 预编译器的绝对依赖
- **`:has()` 父选择器（Parent Selector）**：允许根据子元素状态反向匹配并修饰父容器
- **容器查询（Container Queries `@container`）**：按组件容器自身尺寸响应式排版，而非仅依据全局视口
- **子网格（Subgrid）**：支持多层嵌套元素继承父级 Grid 网格线对齐

**工程影响与选型建议：**

> 彻底改变了 Web 组件化排版与样式架构的设计思路。

### CSS Grid 布局（2017 年 3 月）

**主要功能与架构演进：**

- 二维网格布局系统（`display: grid`）全量普及于各大现代浏览器
- 支持 `grid-template-columns: repeat(auto-fit, minmax(200px, 1fr))` 极简自适应网格

**工程影响与选型建议：**

> 复杂二维仪表盘与响应式页面布局的终极方案。

### CSS Flexbox 布局（2015 年 6 月）

**主要功能与架构演进：**

- 一维弹性盒子排版（`display: flex`）
- 彻底消除了传统 `float` 浮动与 `inline-block` 垂直居中对齐的痛点

**工程影响与选型建议：**

> 全网 Web 布局的事实标准基石。

### CSS3 模块化（2011 年起）

**主要功能与架构演进：**

- 媒体查询（Media Queries `@media`）开启移动优先响应式设计（RWD）时代
- 圆角（`border-radius`）、阴影（`box-shadow`）、过渡与关键帧动画（`transition`, `@keyframes`）

**工程影响与选型建议：**

> Web 视觉表现力与动态交互的质变。

## 浏览器兼容建议
- 现代特性（如 `:has()` 与 原生 Nesting）在 2023+ 主流浏览器均已全量支持（Baseline 普及），无需配置额外 Polyfill。
