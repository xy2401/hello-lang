# Go 1.26

> **参考官方文档**：[Go 官方发布说明](https://go.dev/doc/go1.26)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Go 1.26 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2026 年 2 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** Go

## 核心变化

- 允许 `new` 接收表达式并直接创建带初值的指针
- 继续改进工具链、运行时和标准库
- 保持 Go 1 源码兼容承诺

## 兼容与迁移

- 升级后运行 `go fix`、`go vet` 与全量测试，并重新验证 cgo、编译器插件和构建镜像。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
go version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
