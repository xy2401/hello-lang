## 1. 🔀 Generics (基于 Type Parameters 的泛型)
引入参数化类型约束（如 `[T any]` 或 `[T Number]`），使得在保持编译期强类型安全的同时极大地减少类型重复逻辑。

```go
// 关联源码: demos/go/generics_demo.go
type Number interface {
    ~int | ~int64 | ~float64
}

func Sum[T Number](numbers []T) T {
    var total T
    for _, n := range numbers {
        total += n
    }
    return total
}
```
