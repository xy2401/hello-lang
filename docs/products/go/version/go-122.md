## 1. 🔄 `for` 循环迭代变量作用域彻底修正
在 Go 1.22 以前，`for` 循环的循环变量是在每次迭代中复用的，导致在循环中启动 Goroutine 闭包时极易引发并发 Bug。Go 1.22 开始，每次迭代均创建全新的变量实例。

```go
// 关联源码: demos/go/loop_scope_demo.go
values := []string{"a", "b", "c"}
for _, v := range values {
    go func() {
        fmt.Println(v) // Go 1.22 原生输出 a, b, c，无需手动 v := v！
    }()
}
```
