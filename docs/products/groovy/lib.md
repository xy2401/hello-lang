# Groovy 常用外部依赖库（Gradle/Maven）

## 📦 Web 框架
- **Grails** - Ruby on Rails 风格的 Web 框架
- **Spock Framework** - BDD 测试框架
- **Jersey** - JAX-RS RESTful API

## 🔧 实用工具库
- **Grailss** - Grails CLI 工具
- **GORM** - ORM 映射层
- **Gant** - 构建脚本工具
- **JsonSlurper** - JSON 解析器

## 🧪 测试工具
- **Spock** - Groovy 专属 BDD 框架
- **JUnit** - Java 兼容测试
- **AssertJ** - 流畅断言

## 🏗️ 构建与工具
- **Gradle** - 基于 Groovy 的构建系统
- **Apache Grape** - 包管理工具
- **Groovy-SQL** - SQL 处理

## ⚠️ 已废弃/不推荐
- **Grails 2.x** 🔴 - 旧版本，建议升级到 Grails 4+/5+
- **Ant-Groovy** 🔴 - 已被 Gradle 替代
