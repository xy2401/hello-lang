# Groovy 常用类库索引

Groovy 是 JVM 的动态语言，与 Java 无缝集成。

## 📦 核心类库分类

### 标准库（groovy.*）
- **集合扩展** - List、Map 的便捷方法
- **闭包** - Closures
- **AST 变换** - @Grab, @CompileStatic
- **XML/JSON** - slurp, serialize
- **正则表达式** - Pattern、Matcher 增强

### Web 开发
- **Web 框架** - Grails/Gorm, Spock Framework
- **HTTP 客户端** - Apache HttpClient, REST Assured
- **模板引擎** - GSP, Freemarker, Thymeleaf

### 测试与验证
- **测试框架** - Spock（BDD 风格）、JUnit 4/5
- **Mock 工具** - MockFactory, GroovyMock
- **代码覆盖** - Jacoco

### 构建与自动化
- **Gradle** - 基于 Groovy 的构建系统
- **Grails/Graffiti** - Web 应用框架
- **GORM** - 对象关系映射

### 集成与工具
- **Apache 项目** - Ant, Ivy, Maven
- **容器化** - Docker, Kubernetes
- **监控** - AppDynamics, New Relic

---

*注：Gradle 是基于 Groovy 的最著名项目*
