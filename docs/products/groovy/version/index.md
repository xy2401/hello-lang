# Groovy 版本演进

- [Groovy 5.1](./groovy-5.1)：当前稳定线，面向 JDK 11+。
- [Groovy 5.0](./groovy-5.0)：新语法与语言整理的第五代主线。
- [Groovy 4.0](./groovy-4.0)：`org.apache.groovy` 坐标迁移。
- [Groovy 3.0](./groovy-3.0)：Parrot parser 与现代语法。
- [Groovy 2.4](./groovy-2.4)：大量遗留 Gradle/Jenkins 环境的历史基线。

版本选择还必须服从 Gradle、Jenkins、Spock 和目标 JDK 的兼容范围。
