# HTML 常用类库索引

HTML 是 Web 页面的基础标记语言，配合 CSS 和 JavaScript 使用。

## 📦 HTML5 核心特性

### 语义化标签
- **结构化** - header, nav, main, section, article, aside, footer
- **表单增强** - input type="email", "url", "date", "time"
- **多媒体** - video, audio, canvas, svg
- **图形化** - figure, figcaption, time, progress, meter

### 表单与验证
- **新类型** - number, range, color, search, tel, url
- **约束验证** - required, pattern, min, max, step
- **自动完成** - autocomplete、formaction、formnovalidate
- **无障碍** - aria-label、role、tabindex

### 存储与离线
- **localStorage** - 本地键值存储
- **sessionStorage** - 会话级存储
- **IndexedDB** - 客户端数据库
- **Cache API** - 离线缓存策略

### 网络通信
- **WebSocket** - WebSocket API
- **Web Workers** - 后台线程
- **Fetch API** - 现代 HTTP 请求
- **Service Workers** - 离线支持

---

*注：HTML5 是 Web 标准的基础，建议配合 Modernizr 检测功能支持*
