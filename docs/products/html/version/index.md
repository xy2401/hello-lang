# HTML 版本演进

HTML 标准由 WHATWG 以 **HTML Living Standard** 持续维护演进，现代浏览器持续普及原生高级交互组件。

## 版本索引

### [HTML Living Standard (现代特性)](./modern-html)

- **发布时间：** 2023 年–2024 年
- **版本重点：** 原生 标签：支持全平台统一的模态弹窗与无障碍焦点捕获（.showModal()）。

### [HTML5 (W3C 推荐标准)](./html5)

- **发布时间：** 2014 年 10 月
- **版本重点：** 结构化语义标签：, , , , ,。

### [HTML 4.01](./html-4.01)

- **发布时间：** 1999 年 12 月
- **版本重点：** 确立基于表现（CSS）与结构（HTML）严格分离的设计思想。

## 现代 Web 规范
- 现代页面文档头部必须声明简短的 `<!DOCTYPE html>` 触发标准渲染模式。
