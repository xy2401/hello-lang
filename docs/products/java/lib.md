# Java 常用外部依赖库

## 📦 Web 开发框架
- **Spring Boot** - Spring 生态核心框架，用于构建微服务和 RESTful API
- **Vert.x** - 响应式 Web 框架，高性能异步处理
- **Play Framework** - 轻量级 Web 框架

## 🗄️ 数据库与 ORM
- **Hibernate/JPA** - ORM 标准实现
- **MyBatis** - 灵活的数据映射框架
- **JDBC** - 原生数据库访问

## 🧪 测试框架
- **JUnit 5** - 主流单元测试框架
- **Mockito** - Mock 对象创建
- **AssertJ** - 流畅断言库

## 🔧 实用工具库
- **Lombok** - 简化代码（getter/setter 等）
- **Apache Commons** - 通用工具集
- **Guava** - Google 扩展库（集合、缓存等）
- **SLF4J + Logback** - 日志框架
- **Jackson** - JSON 序列化/反序列化
- **Gson** 🔴 - 较旧，Jackson 更推荐

## 🌐 网络通信
- **OkHttp** - HTTP 客户端
- **Netty** - 高性能网络框架

## 🏗️ 构建工具
- **Maven** - 构建与依赖管理
- **Gradle** - 灵活构建系统
