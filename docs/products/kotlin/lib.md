# Kotlin 常用类库索引

Kotlin 是 JetBrains 开发的现代语言，与 Java 完全互操作。

## 📦 核心类库分类

### 标准库（stdlib）
- **集合** - List, Map, Sequence
- **函数式编程** - map, filter, reduce, let, run
- **空安全** - nullable types, safe call operator
- **协程** - kotlinx.coroutines
- **扩展函数** - Extension functions

### 平台支持
- **Android** - Jetpack Compose, Room, ViewModel, LiveData
- **JVM 后端** - Spring Boot, Ktor
- **Native** - kotlin-native（iOS、嵌入式）
- **WebAssembly** - Kotlin/JS

### Web 开发框架
- **服务器端** - Ktor, Spring Boot + Kotlin
- **客户端** - Compose Multiplatform
- **API 生成** - Retrofit, OkHttp

### ORM 与数据库
- **ORM** - Exposed, Hibernate (via Spring)
- **查询构建** - Jooq, SQLDelight
- **NoSQL** - MongoDB driver, Redis client

### 测试工具
- **测试框架** - JUnit, Kotest, MockK
- **Mock 工具** - MockK, Mockito-Kotlin
- **代码覆盖** - JaCoCo

### 工具链
- **构建工具** - Gradle（Kotlin DSL）、Maven
- **依赖管理** - Maven Central, Google Repositories
- **代码格式** - ktlint, Detekt

---

*注：Android 官方推荐语言，同时适合 JVM 后端开发*
