# Kotlin 常用外部依赖库（Maven/Gradle）

## 📦 Web 框架
- **Spring Boot + Kotlin** - JVM 后端主流框架
- **Ktor** - 轻量级异步 Web 框架（JetBrains 开发）
- **Exposed** - SQL 库（JetBrains 开发）

## 🗄️ 数据库与 ORM
- **Hibernate/JPA** - Java 生态 ORM
- **Exposed** - Kotlin 原生 SQL 库
- **SQLDelight** - 类型安全 SQL
- **Armeria** - gRPC 客户端

## 🤖 Android 开发
- **Jetpack Compose** - 现代声明式 UI
- **Room** - SQLite ORM
- **ViewModel** - 生命周期感知组件
- **LiveData** - 可观察数据
- **Coroutines** - 协程支持

## 🧪 测试工具
- **JUnit 5** - 单元测试框架
- **Kotest** - Kotlin 原生测试框架
- **MockK** - Mock 对象生成器
- **AssertJ-Kotlin** - 流畅断言

## 🔧 实用工具库
- **Kotlinx.serialization** - 序列化框架
- **OkHttp** - HTTP 客户端
- **Gson/Jackson** - JSON 处理
- **Arrow** - 函数式编程扩展
- **Kotlinx.coroutines** - 协程库

## ⚠️ 已废弃/不推荐
- **RxJava** 🔴 - 学习曲线陡峭，建议优先使用协程
- **Butterknife** 🔴 - 已被 ViewBinding 替代
