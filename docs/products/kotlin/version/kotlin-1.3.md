# Kotlin 1.3

> **参考官方文档**：[Kotlin 官方发布说明](https://kotlinlang.org/docs/releases.html)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Kotlin 1.3 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2018 年 10 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** Kotlin

## 核心变化

**主要功能与架构演进：**

- **协程（Coroutines）** 正式发布 GA 稳定版，确立挂起函数（`suspend`）异步流式编程模型
- 引入内联类（Inline Classes）与无符号整数类型

**工程影响与选型建议：**

> Android 与服务端异步高并发编程的首选基准。

## 兼容与迁移

- 同时更新编译器或运行时、包管理器、构建镜像与 CI，不只修改本机版本。
- 先处理弃用警告，再验证依赖、代码生成器、原生扩展和目标平台。
- 在新旧基线分别运行测试，明确产物的最低运行时与语言版本。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
kotlinc -version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
