# Lisp 常用外部依赖库

## 📦 Common Lisp
- **Quicklisp** - 包管理工具（必备）
- **ASDF** - 构建系统
- **Hunchentoot** - Web 服务器
- **Trivial-HTTP-Server** - 轻量级 HTTP 服务
- **Postmodern** - PostgreSQL 适配器
- **Cl-JSON** - JSON 处理

## 🎨 GUI 框架
- **Clover** - Common Lisp GUI 框架
- **XBL** - XBL 绑定库
- **Qtools** - Qt 封装

## 🔧 实用工具库
- **Alexandria** - 通用工具函数
- **Serve-Handler** - 请求处理
- **Clack** - HTTP 服务器抽象层
- **Incanter** - 数据分析与可视化

## ⚠️ 已废弃/不推荐
- **CL-HTTP** 🔴 - 旧 Web 框架，已被 Hunchentoot 替代
- **MARC21** 🔴 - 过时的元数据标准
