# Lua 常用外部依赖库（ Luarocks）

## 📦 Web 框架
- **Luakit** - Web 浏览器框架
- **Lapis** - OpenResty Web 框架
- **Wren** - Web 应用框架

## 🔧 实用工具库
- **luasocket** - TCP/UDP 网络通信（必备）
- **lualib** - 标准库扩展
- **Penlight** - 函数式编程库
- **Fennel** - Lisp 语法变体
- **LuaSQL** - 数据库访问

## 🎮 游戏开发
- **Love2D (LÖVE)** - 2D 游戏引擎
- **Corona SDK** - 移动游戏开发
- **Solar2D** - Corona 开源替代版

## 🗄️ 数据库与缓存
- **LuaSQL** - 多数据库支持
- **lua-redis** - Redis 客户端
- **lfs** - 文件系统操作

## 🧪 测试工具
- **Busted** - Lua 测试框架
- **LuaSpec** - BDD 测试
- **Toss** - 轻量级测试框架

## ⚠️ 已废弃/不推荐
- **LuaRocks 1.x** 🔴 - 旧版本包管理器
- **ZeroMQ-lua** 🔴 - 使用减少，建议使用 luazmq
