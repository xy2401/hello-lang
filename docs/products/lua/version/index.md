# Lua 版本路线

Lua 的小版本线不是“仅增加 API”的兼容层。5.1、5.2、5.3、5.4、5.5 在整数模型、环境、协程、GC、C API 和标准库上都有边界；预编译字节码也不应跨版本复用。

| 版本线 | 迁移关注点 |
| --- | --- |
| 5.1 | `setfenv/getfenv`、旧模块习惯、LuaJIT 常见兼容基线 |
| 5.2 | `_ENV`、`goto`、库调整 |
| 5.3 | 整数子类型、位运算符、C API 数值边界 |
| 5.4 | `<close>`、`<const>`、协程与 GC 变化；5.4.9 为该系列最终维护版 |
| 5.5 | `global`、命名变参 Table、数组布局与 GC 更新；本项目使用 5.5.1 |

- [Lua 5.5 运行基线](./lua-5.5)

部署时应让解释器、原生模块、头文件和链接库来自同一版本构建。不要把不同小版本的 ABI 或二进制 chunk 当作稳定接口。
