# Lua 5.5 运行基线

## 发布信息

本项目采用 Lua 5.5.1 正式版本，并从官方源码包构建运行镜像；Lua 5.4.9 是 5.4 系列的最终维护版。版本状态、发布日期和源码归档以 [Lua 官方版本历史](https://www.lua.org/versions.html) 与 [Lua 官方源码目录](https://www.lua.org/ftp/) 为准。

## 语言变化

Lua 5.5 引入显式 `global` 声明、命名变参 Table、更紧凑的数组表示和垃圾回收调整。源码 SHA-256 固定在 Dockerfile 中，解释器、`luac`、头文件和链接库来自同一次构建。

## 迁移影响

从 5.4 迁移时，应先检查解析阶段不兼容的新语法、C API 编译边界、原生模块 ABI 与二进制 chunk。需要同时支持 5.4 和 5.5 的项目，应维护不同入口或限制为两条版本线都能解析的语法，并重新编译所有原生模块。
