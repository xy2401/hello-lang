# PHP 8.0

> **参考官方文档**：[PHP 官方发布说明](https://www.php.net/releases/)  
> 本页依据正式 Release 与现有仓库版本证据，整理 PHP 8.0 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2020 年 11 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** PHP

## 核心变化

**主要功能与架构演进：**

- 引入 JIT（即时编译器）
- 命名参数（Named Arguments）、联合类型（Union Types `int|string`）、Match 表达式
- 构造器属性提升（Constructor Property Promotion）与注解（Attributes `#[Attr]`）

**工程影响与选型建议：**

> 现代 PHP 8 世代的绝对奠基版本。

## 兼容与迁移

- 同时更新编译器或运行时、包管理器、构建镜像与 CI，不只修改本机版本。
- 先处理弃用警告，再验证依赖、代码生成器、原生扩展和目标平台。
- 在新旧基线分别运行测试，明确产物的最低运行时与语言版本。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
php --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
