## 核心变化

**主要功能与架构演进：**

- 属性钩子（Property Hooks）：原生支持 `get` 与 `set` 访问器逻辑，减少冗余样板代码
- 非对称可见性（Asymmetric Visibility）：支持公共读取私有写入（`public private(set)`）
- 支持 `new MyClass()->method()` 链式直接调用（无需外层包裹括号）

**工程影响与选型建议：**

> 面向对象语法简洁性看齐 Swift 与 Kotlin。
