# PHP 8.5

> **参考官方文档**：[PHP 官方发布说明](https://www.php.net/releases/8_5_0.php)  
> 本页依据正式 Release 与现有仓库版本证据，整理 PHP 8.5 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2025 年 11 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** PHP

## 核心变化

- 加入 URI 扩展和管道运算符 `|>`
- 加入 Clone With 与 `#[NoDiscard]`
- 常量表达式支持闭包、类型转换和一等可调用对象

## 兼容与迁移

- 按官方迁移指南处理不兼容行为和弃用项，重新构建扩展并验证 Composer 依赖与静态分析规则。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
php --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
