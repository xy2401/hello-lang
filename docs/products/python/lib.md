# Python 常用外部依赖库

## 📦 Web 框架
- **Django** - 全功能 Web 框架（自带 ORM、Admin）
- **FastAPI** - 现代异步 API 框架（高性能）
- **Flask** - 轻量级微型框架
- **Sanic** - 高速异步 Web 框架

## 🗄️ 数据库与 ORM
- **SQLAlchemy** - 主流 ORM（支持同步/异步）
- **Peewee** - 轻量级 ORM
- **Django ORM** - Django 内置 ORM

## 🧪 测试工具
- **Pytest** - 最流行的测试框架
- **unittest** - Python 标准测试库
- **Faker** - Mock 数据生成器
- **responses** - HTTP 请求 Mock

## 🔧 数据处理与分析
- **Pandas** - 数据分析处理
- **NumPy** - 数值计算基础
- **Requests** - HTTP 客户端（必备）
- **BeautifulSoup4** - HTML/XML 解析

## 🤖 AI 与机器学习
- **Scikit-learn** - 传统机器学习
- **PyTorch** - Facebook 深度学习框架
- **TensorFlow** - Google 深度学习框架
- **HuggingFace transformers** - NLP 预训练模型
- **LangChain** - LLM 应用开发框架

## 🏗️ 工程化
- **Black** - 代码格式化工具
- **Ruff** - 快速 Linter（替代 flake8）
- **Poetry** - 现代化包管理
- **Mypy** - 类型检查工具
