# Python 常用类库索引

Python 拥有庞大而活跃的生态系统，涵盖各个领域。

## 📦 核心类库分类

### 标准库精选
- **itertools** - 迭代工具函数
- **functools** - 高阶函数工具
- **collections** - 特殊数据类型（deque, Counter, defaultdict）
- **pathlib** - 面向对象的路径处理
- **contextlib** - 上下文管理器工具
- **concurrent.futures** - 并发编程
- **json/urllib** - HTTP 请求与数据交互

### Web 开发框架
- **Web 框架** - Flask, Django, FastAPI, Bottle
- **WSGI 服务器** - Gunicorn, uWSGI
- **异步 Web** - aiohttp, Sanic, Starlette
- **ORM** - SQLAlchemy, Django ORM, Peewee

### 数据分析与科学计算
- **数据处理** - NumPy, Pandas, Polars
- **可视化** - Matplotlib, Seaborn, Plotly
- **机器学习** - Scikit-learn, XGBoost
- **深度学习** - PyTorch, TensorFlow, Keras
- **Jupyter** - IPython, Jupyter Notebook/Lab

### 测试与工程化
- **单元测试** - unittest, pytest, nose2
- **Mock 测试** - unittest.mock, Faker,responses
- **类型检查** - mypy, pyright, pyre
- **代码质量** - flake8, black, isort, pylint
- **包管理** - pip, poetry, conda, pipenv

### AI 与大模型
- **NLP** - NLTK, spaCy, gensim
- **AI 框架** - Hugging Face transformers
- **LLM 应用** - LangChain, LlamaIndex

---

*注：Python 的"电池内置"理念体现在其丰富的标准库中*
