## 1. 🔷 PEP 695：类型参数语法
允许直接在类与函数名后使用 `[T]` 声明泛型类型，免去 `TypeVar` 繁琐定义。

```python
# 关联源码: demos/python/type_param_demo.py
class Stack[T]:
    def __init__(self) -> None:
        self.items: list[T] = []

    def push(self, item: T) -> None:
        self.items.append(item)
```

## 2. 📝 PEP 701: 规范化 F-Strings 语法 (Formalized F-Strings)
取消了内部引号嵌套限制、表达式反斜杠限制与多行表达式限制。

```python
# 关联源码: demos/python/fstring_demo.py
user = {"name": "Alice"}
result = f"User: {user['name']!r}, List: {', '.join(['a', 'b'])}"
```
