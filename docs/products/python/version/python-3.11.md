## 核心变化

**主要功能与架构演进：**

- Faster CPython 计划落地：自适应特化解释器（Specializing Adaptive Interpreter），执行性能提升 10%~60%
- 细粒度错误追溯定位（Enhanced Error Tracebacks），报错精确定位到行内具体子表达式

**工程影响与选型建议：**

> 解释器运行效率的巨大跨越。
