## 核心变化

**主要功能与架构演进：**

- 实验性自由线程 CPython（Free-threaded CPython，可禁用 GIL 全局解释器锁，实现真正多核并行计算）
- 实验性即时编译器（JIT Compiler，基于 Copy-and-Patch 技术）
- 全新的交互式 REPL 终端：支持彩色多行编辑、自动缩进与直接查看函数签名文档

**工程影响与选型建议：**

> 开启 Python 真正多核并行与 JIT 时代的历史性转折点。
