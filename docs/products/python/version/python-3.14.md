# Python 3.14

> **参考官方文档**：[Python 官方发布说明](https://www.python.org/downloads/release/python-3140/)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Python 3.14 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2025 年 10 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** Python

## 核心变化

- 自由线程构建进入正式支持
- 注解改为延迟求值并加入模板字符串字面量
- 标准库加入多解释器与 Zstandard 压缩支持

## 兼容与迁移

- 检查 C 扩展对自由线程构建的兼容、注解反射行为和已移除 API；按虚拟环境重建全部二进制依赖。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
python --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
