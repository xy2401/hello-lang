# Ruby 常用外部依赖库（Gem）

## 📦 Web 框架
- **Ruby on Rails** - 全功能 MVC 框架（最流行）
- **Sinatra** - 轻量级微框架
- **Hanami** - 模块化 Web 框架
- **Grape** - API 构建器

## 🗄️ 数据库与 ORM
- **ActiveRecord** - Rails 内置 ORM
- **Sequel** - 灵活 SQL 适配器
- **Tango** - 现代 ORM

## 🧪 测试工具
- **RSpec** - BDD 测试框架（主流）
- **Minitest** - Ruby 标准测试库
- **Cucumber** - BDD 工具
- **FactoryBot** - 工厂模式支持

## 🔧 实用工具库
- **Bundler** - 包管理器（必备）
- **Puma** - HTTP 服务器
- **Sidekiq** - 后台任务队列
- **Pagy** - 分页器
- **Omniauth** - OAuth 认证
- **Dry-RS** - 数据验证

## ⚠️ 已废弃/不推荐
- **Rails 3.x** 🔴 - 旧版本，建议升级到 Rails 7+
- **Capistrano 2** 🔴 - 旧部署工具，建议 Cap v3+
