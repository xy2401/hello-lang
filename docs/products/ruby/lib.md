# Ruby 常用类库索引

Ruby 以其优雅语法和丰富 gem 生态著称。

## 📦 核心类库分类

### 标准库（stdlib）
- **字符串** - String, Regexp
- **集合** - Array, Hash, Set, Enumerable
- **并发** - Fiber, Thread, Mutex
- **网络** - Net::HTTP, Socket, Webrick
- **测试** - TestUnit（内置）

### Web 框架
- **Ruby on Rails** - Full-stack MVC 框架
- **微框架** - Sinatra, Hanami, Camping
- **API 框架** - Grape, JSON:API
- **实时通信** - Action Cable

### ORM 与数据访问
- **ActiveRecord** - Rails 内置 ORM
- **Oj** - Fast JSON parsing
- **数据库适配器** - PostgreSQL, MySQL, SQLite3

### 测试与工具
- **测试框架** - RSpec, Minitest, Cucumber（BDD）
- **Mock 工具** - RSpecMocks, Mocha
- **代码覆盖** - SimpleCov
- **包管理** - Bundler, Gem

### 实用工具
- **时间处理** - ActiveSupport, ActiveModel
- **日志系统** - Logger, Log4r, puma
- **异步编程** - Sidekiq, Resque（后台任务）
- **前端集成** - Turbolinks, Stimulus, Hotwire

### DevOps 与部署
- **容器化** - Docker, Heroku
- **服务器管理** - Chef, Puppet, Ansible
- **监控** - New Relic, Datadog

---

*注：Rails 是 Ruby 最著名的框架，适合快速开发*
