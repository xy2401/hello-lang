# Ruby 3.0 (Ruby3x3)

> **参考官方文档**：[Ruby 官方发布说明](https://www.ruby-lang.org/en/downloads/releases/)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Ruby 3.0 (Ruby3x3) 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2020 年 12 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** Ruby

## 核心变化

**主要功能与架构演进：**

- 达成比 Ruby 2.0 执行速度提升 3 倍的宏伟目标
- 引入 Ractor 并发模型（实现真正的并行多核执行，无共享数据）
- 引入 RBS 类型声明文件规范支持静态类型分析

**工程影响与选型建议：**

> 开启 3.x 时代性能与类型生态重构。

## 兼容与迁移

- 同时更新编译器或运行时、包管理器、构建镜像与 CI，不只修改本机版本。
- 先处理弃用警告，再验证依赖、代码生成器、原生扩展和目标平台。
- 在新旧基线分别运行测试，明确产物的最低运行时与语言版本。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
ruby --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
