# Ruby 4.0

> **参考官方文档**：[Ruby 官方发布说明](https://www.ruby-lang.org/en/news/)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Ruby 4.0 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2025 年 12 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** Ruby

## 核心变化

- 进入新的语言与运行时主版本线
- 继续强化 YJIT、解析器、核心类库和开发工具
- 采用更频繁的稳定补丁发布节奏

## 兼容与迁移

- 升级前核对 Gem 原生扩展、Rails 与 Bundler 支持矩阵，处理已移除 API 并重新生成锁文件平台信息。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
ruby --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
