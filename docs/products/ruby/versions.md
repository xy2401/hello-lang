# Ruby 版本演进

Ruby 坚持每年圣诞节（12 月 25 日）发布主版本的传统。从 Ruby 3.0 开始通过 YJIT 与 Ractor 大幅冲刺执行性能与并发能力。

## 核心版本演进与关键里程碑

### Ruby 3.3（2023 年 12 月）

**主要功能与架构演进：**

- 引入全新纯 C 开发的高性能 Prism 解析器
- YJIT（Yet Another JIT）编译器性能再度提升 15%~30%，并在 Shopify/GitHub 等大规模生产环境广泛部署
- 引入纯 Ruby JIT 编译器 RJIT

**工程影响与选型建议：**

> 现代 Ruby on Rails 生产环境的最佳运行基线。

### Ruby 3.2（2022 年 12 月）

**主要功能与架构演进：**

- YJIT 编译器正式宣布进入生产就绪（Production-ready）状态
- 原生支持 WebAssembly/WASI 编译目标，直接在浏览器和边缘沙箱运行 Ruby

**工程影响与选型建议：**

> JIT 编译器成熟落地的关键里程碑。

### Ruby 3.0 (Ruby3x3)（2020 年 12 月）

**主要功能与架构演进：**

- 达成比 Ruby 2.0 执行速度提升 3 倍的宏伟目标
- 引入 Ractor 并发模型（实现真正的并行多核执行，无共享数据）
- 引入 RBS 类型声明文件规范支持静态类型分析

**工程影响与选型建议：**

> 开启 3.x 时代性能与类型生态重构。

## 性能调优提示
- 在生产启动 Ruby 3.3+ 时添加环境变量 `RUBY_YJIT_ENABLE=1` 即可零成本激活 YJIT 即时编译加速。
