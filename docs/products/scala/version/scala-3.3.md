# Scala 3.3 LTS

**官方资料**：[Scala 3.3.8 LTS 发布说明](https://scala-lang.org/news/3.3.8/)。

发布日期：3.3.8 于 2026-06-10 发布，是当前 3.3 LTS 维护版本。该线强调兼容性与缺陷回移，适合作为教程和长期维护服务基线。

## 迁移影响

从 Scala 2 迁移需要处理隐式、宏、集合 API、编译器选项和依赖后缀；从较早 Scala 3 迁移仍要验证 TASTy 与插件版本。

```bash
scala -version
scalac -version
```
