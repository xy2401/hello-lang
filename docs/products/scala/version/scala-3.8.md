# Scala 3.8

**官方资料**：[Scala 3.8.4 下载页](https://www.scala-lang.org/download/3.8.4.html)。

发布信息：Scala 3.8 是 2026 年的当前功能线，继续演进 Scala 3 编译器、类型系统和标准工具，并与 3.3 LTS 承担不同升级节奏。

## 迁移影响

从 3.3 LTS 升级前检查编译器插件、宏、TASTy、sbt 与库的 Scala 3 交叉发布。生产系统若更看重稳定窗口可继续使用 3.3 LTS。

```bash
scala -version
scalac -version
```
