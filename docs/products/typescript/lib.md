# TypeScript 常用类库索引

TypeScript 作为 JavaScript 的类型超集，拥有丰富的生态系统。

## 📦 核心类库分类

### 类型系统与基础工具
- **类型守卫** - Type Guards, Narrowing
- **Utility Types** - Partial, Pick, Omit, Required
- **泛型工具** - Generic utility types, Conditional types
- **装饰器** - Class/Method property decorators

### Web 开发栈
- **框架** - React, Vue, Svelte, Angular
- **状态管理** - Redux, Zustand, Jotai, Pinia
- **HTTP 客户端** - Axios, Fetch API, superagent
- **API 生成** - OpenAPI/Swagger codegen, tRPC

### 测试与验证
- **测试框架** - Jest, Vitest, Mocha
- **类型测试** - tsd, expect-type
- **E2E 测试** - Cypress, Playwright, Selenium
- **表单验证** - Zod, Yup, Joi, valibot

### 实用工具库
- **函数式编程** - Lodash, Ramda
- **日期处理** - date-fns, dayjs, Luxon
- **数据验证** - class-validator, ajv
- **日志工具** - Winston, Pino, tslog

---

*注：根据具体项目需求选择合适的类库*
