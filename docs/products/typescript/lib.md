# TypeScript 常用外部依赖库

## 📦 Web 框架
- **React** - UI 组件库（配合 JSX）
- **Vue 3** - 渐进式前端框架
- **Angular** - 企业级全功能框架
- **Svelte** - 轻量级编译时框架

## 🌐 网络通信
- **Axios** - HTTP 客户端
- **Fetch API** - 原生浏览器 API
- **tRPC** - 类型安全后端 API

## 🧪 测试工具
- **Jest** - 单元测试框架
- **Vitest** - Vite 生态测试
- **Playwright** - E2E 自动化测试
- **Cypress** - E2E 测试工具

## 🔧 实用工具库
- **Lodash** - 函数式编程工具集
- **Zod** - TypeScript 类型验证
- **dayjs** - 日期处理（比 Moment.js 轻）
- **date-fns** - 模块化日期库

## ⚠️ 已废弃/不推荐
- **jQuery** 🔴 - DOM 操作，现代框架已替代
- **Moment.js** 🔴 - 体积大，已被 dayjs/nano-date 替代
- **RxJS** 🔴 - 学习曲线陡峭，谨慎使用
